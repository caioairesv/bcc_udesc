## Organização das disciplinas

Cada disciplina possui uma pasta própria, contendo, conforme necessário:

```text
disciplina/
├── README.md
├── aulas/
├── exercicios/
├── trabalhos/
├── projetos/
└── provas/
```

A organização pode variar de acordo com as necessidades de cada disciplina.

## Objetivo

Centralizar e organizar o material produzido durante a graduação, facilitando a consulta, revisão e continuidade dos estudos ao longo do curso.
